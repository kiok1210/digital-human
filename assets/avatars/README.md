# 虚拟人像库

把可用的虚拟人像（`.jpg` / `.jpeg` / `.png` / `.webp`）放进这个目录，
刷新页面后即可在「选择人像 → 虚拟人像」里直接点选，无需每次上传。

- 文件名（去掉扩展名）会作为形象名称显示在页面上。
- 建议使用正面、脸部清晰、无遮挡的半身或头像图。
- 请仅使用拥有合法授权的虚拟形象素材。

项目内置的「知识主播·珊瑚」「科技主播·靛蓝」「生活主播·薄荷」由
OpenAI Image Generator 为本项目生成，构图已针对 SadTalker 的正脸口型驱动优化。

旧版示例图保存在 `legacy/`，不会出现在创作台的人像列表中。
